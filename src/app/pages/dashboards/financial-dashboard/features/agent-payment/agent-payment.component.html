Paiement des agents

Sélectionnez un ou plusieurs agents : le même montant leur sera appliqué. Pour un agent avec un numéro Orange Money ou Moov Money reconnu, la demande déclenche un virement réel (Orange Money essayé en premier), mais seulement après validation par un administrateur — aucun virement n'est envoyé à la création. Pour un agent sans numéro fiable, le paiement reste interne (effectué hors plateforme) et immédiat, sans effet sur le solde de l'agence.
