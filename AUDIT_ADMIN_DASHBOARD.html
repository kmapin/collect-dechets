1. Présentation Générale du Rôle Super Admin

Le Super Administrateur est le rôle de plus haut niveau de la plateforme Collect Déchets. Il assure la supervision globale de l'ensemble de l'écosystème de gestion des déchets à Ouagadougou et dans d'autres villes du Burkina Faso.

Responsabilités principales :
  • Supervision et audit de toutes les agences de collecte
  • Gestion des agents de mairie (municipalités)
  • Consultation et gestion de tous les utilisateurs (clients, collecteurs, managers)
  • Suivi des incidents et signalements à l'échelle nationale
  • Analyse des statistiques consolidées de la plateforme
  • Communication vers les agences et parties prenantes
  • Activation / désactivation des agences et comptes

3. Fonctionnalités RÉALISÉES (connectées à l'API) ✅

3.1 Chargement & affichage des statistiques globales

Méthode : showAdminStatistics() → adminService.getAllStatistics()
Description : Au chargement de la page, l'admin voit en temps réel le nombre d'agences, clients, collecteurs, collectes du jour et incidents non résolus.
Loader : Spinner de chargement pendant la récupération des données.

3.2 Audit des Agences (onglet Agences)

Méthode : loadAgencyAudits(filterParams) → agencyService.getAllAgenciesFromApi()
Données affichées par agence :
  • Nom de l'agence
  • Statut (active / inactive / deleted) avec badge coloré
  • Score de conformité (calculé côté frontend, actuellement = 0)
  • Nombre de clients
  • Nombre de collecteurs (employés)
  • Nombre de zones de couverture
  • Collectes du jour (actuellement = 0, non encore calculé)
  • Taux de réalisation (actuellement = 0)
  • Note / Rating (actuellement = 0)
  • Problèmes identifiés (si existants)
Actions disponibles par agence :
  • ✅ Voir Détails : navigation vers la page publique de l'agence (/agencies/:id)
  • ✅ Contacter : redirection vers la page de l'agence (messagerie non encore intégrée directement)
  • ✅ Activer : activation d'une agence inactive via activateAgency()
  • ❌ Auditer : bouton commenté, fonctionnalité non implémentée
Filtres : Recherche par nom, filtre par statut (toutes / actives / inactives / supprimées).

3.3 Gestion des Utilisateurs (onglet Utilisateurs)

Méthode : showAdminUsers(filterParams) → adminService.getAllUsers()
Description : Vue consolidée de tous les utilisateurs de la plateforme (clients, managers, collecteurs, agents de mairie).
Données affichées :
  • Prénom / Nom
  • Rôle (badge coloré)
  • Statut (Actif / Inactif)
  • Avatar ou initiales colorées
  • Ville / Quartier
  • Téléphone
Filtres :
  • Recherche par nom
  • Filtre par rôle (Client / Manager / Collecteur / Agent Mairie)
  • Filtre par quartier (liste générée depuis les données géographiques Ouagadougou)
Actions :
  • ✅ Voir Détails : ouvre un drawer latéral (PrimeNG Drawer) avec les informations complètes de l'utilisateur via adminService.getUserById()

3.4 Gestion des Incidents (onglet Incidents)

Méthode : loadAllSignalements()
Description : L'admin voit tous les signalements de toutes les agences. Utilise le composant partagé app-signalement.
Filtres : Statut (tous / en cours / résolus), Gravité (critique / élevée / moyenne / faible).
Types d'incidents : Collecte manquée, Non-conformité, Réclamation, Problème technique.
Actions fonctionnelles (via composant Signalement) :
  • ✅ Visualiser les incidents
  • ✅ Résoudre un incident
  • ✅ Contacter l'agence concernée

3.5 Couverture Territoriale (onglet Vue d'ensemble)

Méthode : loadZoneStat() → adminService.getAllStatisticCity()
Description : Affichage de la couverture par ville, regroupée par pays. Données combinées API + liste de villes mockée (MOCK_CITIES).
Données par ville : nombre d'agences, clients, collectes du jour, taux de couverture, incidents.

3.6 Gestion des Municipalités (onglet désactivé, code HTML présent)

Méthode : loadAllMunipalities()
Description : Affiche les agents de mairie enregistrés avec nom, téléphone, actions (Détails, Contacter).
Note : L'onglet est commenté dans le tableau tabs[] mais le HTML et la logique sont présents.

3.7 Ajout d'un agent de mairie

Méthode : navigateToAddMunicipality()
Description : Bouton CTA dans la barre de navigation qui redirige vers le formulaire d'inscription d'un agent de mairie. Accessible depuis tous les onglets.

7. Perspectives & Évolutions Futures 🚀

7.1 Intelligence Artificielle & Analytique avancée

Ces fonctionnalités représentent la prochaine génération de la plateforme. Elles nécessitent une maturité des données (historique d'au moins 6 mois).
  • Prédiction de la demande : Algorithme ML pour anticiper le volume de déchets par zone selon la saison, les événements locaux (marchés, fêtes)
  • Optimisation automatique des tournées : Suggestion d'itinéraires optimaux pour les collecteurs basée sur la localisation GPS et la densité clients
  • Détection d'anomalies : Alertes automatiques si une agence dévie de ses performances habituelles (chute de taux de collecte, pic d'incidents)
  • Scoring prédictif des abonnements : Identifier les clients à risque de résiliation avant qu'ils ne résilient

7.2 Application Mobile Administrateur

  • Application mobile légère (PWA ou native) pour l'admin avec accès aux KPIs en déplacement
  • Notifications push en cas d'incident critique
  • Validation d'actions (activation agence, résolution incident) depuis le mobile

7.3 Tableau de Bord Municipalité / Mairie

  • Dashboard dédié aux agents de mairie avec vue sur les agences opérant dans leur commune
  • Rapport de conformité des agences transmis automatiquement à la mairie
  • Interface de délivrance de licences d'exploitation

7.4 Extension géographique

  • Support multi-ville (Bobo-Dioulasso, Koudougou, Banfora)
  • Vue par région avec agrégation des statistiques
  • Gestion de réglementations locales par ville

7.5 Intégrations externes

  • API Mairies : Intégration avec les systèmes informatiques des mairies pour automatiser les rapports réglementaires
  • Partenaires recyclage : Suivi des tonnages envoyés vers les centres de recyclage partenaires
  • Système de paiement : Tableau de bord des transactions (Mobile Money, virement) intégré à un ERP financier
  • Traceur GPS IoT : Intégration de traceurs sur les véhicules de collecte pour suivi en temps réel sur la carte

7.6 Module Gestion de la Qualité (ISO 14001)

  • Indicateurs de performance environnementale (IPE)
  • Suivi du taux de recyclage vs déchets enfouis
  • Documentation de conformité réglementaire exportable pour les audits tiers
